一、我们处理的信息及用途

1. 本机游戏数据

为保存和恢复游戏进度，游戏在应用专用存储空间保存游戏虚拟资金、仓库与装备物品、配件及弹药、干员阵容与成长训练、设施进度、出战和结算状态、行动时间与收益、历史战绩、收藏战绩及当局带回物品快照等数据。声音、难度选择和拾取价值门槛等设置也保存在本机。

游戏还保存必要的存档版本、随机标识、时间、备份及异常恢复记录，用于区分本地物品或行动、避免重复结算和恢复进度。这些标识用于本机游戏逻辑，不用于跨应用跟踪或广告画像。游戏会在本机使用屏幕尺寸、安全显示区域、触控输入及系统时间等运行参数，实现画面适配、操作与训练计时。

上述存档和设置不由游戏自动上传至我们或第三方服务器。游戏引擎可能在应用专用目录记录运行错误等本地日志；当前没有自动上传日志或崩溃报告的功能。我们无法远程访问您的本机进度。

2. 主动反馈与联系

您通过邮箱咨询、报告问题或提出隐私请求时，我们会收到发件邮箱、邮件显示名称、沟通内容，以及您主动附上的截图、存档、日志、设备型号或系统版本等资料，仅用于回复、排查问题、处理请求及必要复核。

请只提供与问题有关的资料，并遮盖截图中的无关个人信息。我们不要求您提供密码、身份证照片或金融账户。是否发送反馈由您决定，不发送不影响正常游玩；缺少排查所必需的信息可能影响具体问题的处理。游戏不会自动发送反馈邮件。

二、设备权限

当前独立 Android 安装包未声明需要向系统申请的应用权限，包括互联网、相机、麦克风、定位、电话、通讯录、短信和共享存储读写权限，也不通过权限弹窗向您索取这些权限。游戏读写自身应用专用存储空间，用于保存进度及设置，无需获得访问相册或共享文件的权限。

此说明针对本游戏当前独立安装包。浏览器、邮件应用及 TapTap 平台有各自的权限和信息处理规则。若后续版本新增需要权限的功能，我们会在实际使用前说明目的、申请时机和拒绝影响，并依法取得必要授权。

三、第三方服务与组件

1. 游戏运行组件

本游戏使用 Godot 引擎及随 Android 导出模板提供的 AndroidX 等基础组件完成图形、音频、输入、文件管理和系统兼容。当前没有接入第三方广告、登录、支付、在线统计或崩溃上报 SDK，也未接入 Tosin 或 TapSDK。基础运行组件不等同于广告或统计服务；当前安装包没有互联网权限，游戏未通过这些组件建立向开发者上传游戏数据的通道。

2. TapTap 平台

您使用 TapTap 查找、下载、评论本游戏，或使用其实际提供的平台功能时，平台会依据自身规则处理相关账号、设备、网络及使用信息；这些平台服务不等于本游戏集成了相应 SDK。平台由易玩（上海）网络科技有限公司提供，详情及联系渠道见TapTap 隐私政策。游戏不会因此取得平台保存的实名资料。

如您通过 TapPlay 等平台运行游戏，并使用平台实际提供的存档备份功能，相关副本的保存、恢复与删除由平台说明及设置决定。这不是开发者提供的云存档；本政策不表示当前已为本游戏开通这些平台功能。

3. 邮件服务

联系邮箱使用 QQ 邮箱。您主动发送邮件时，收发邮件服务商会处理邮件地址、内容及附件，用于传输、存储和安全保障。QQ 邮箱由腾讯提供，适用 QQ 邮箱客户端或网页端公布的《QQ邮箱隐私保护指引》，相关联系渠道也可在该指引中查询。您的发件邮箱适用相应服务商规则。邮件服务未集成在游戏内。

4. 隐私政策网页

本政策网页由 GitHub Pages 托管。您访问网页时，GitHub 会为安全目的记录和保存访问者的 IP 地址，并按其规则处理必要的网页访问数据；其服务可能涉及境外处理。详情及权利请求渠道见GitHub 隐私声明。

本网页不设置表单，不加载广告、访问统计脚本或外部字体，不主动设置 Cookie 或使用浏览器本地存储，也不读取游戏存档。访问网页不等于游戏向 GitHub 上传进度。浏览器、平台或托管服务自身的信息处理以其说明为准。

四、信息保存

本机进度、战绩、收藏、设置与恢复备份保存在您的设备中，随游玩更新，并保存至被游戏规则覆盖、淘汰或由您清除。开始“新游戏”会保留旧进度的恢复备份，因此不等于彻底删除全部本地数据。当前独立安装包关闭了 Android 自动备份；您自行制作的副本、设备迁移副本或平台备份须单独管理。

主动反馈资料保存在联系邮箱和处理问题所必需的工作资料中。我们在中国境内处理收到的反馈，不主动向境外提供这些资料；保存期限以答复、解决问题及必要复核所需的最短时间为限，目的完成且无需继续保存后删除或匿名化。法律法规要求保留的，仅在规定期限和必要范围内保存。

本地数据的位置取决于您的设备所在地。邮件、平台及网页托管服务各自处理的信息，保存地点、期限及删除方式见第三部分列明的服务规则。我们没有本机存档的开发者云端副本。

五、共享、转移与公开披露

我们不出售您的个人信息，不将本机游戏数据用于广告营销，也不主动向广告商或分析服务商提供游戏数据。第三部分说明的邮件传输、平台使用和网页访问由相应服务商按各自服务规则处理。

处理您的具体反馈确需向其他个人信息处理者提供资料时，我们会告知接收方、联系方式、目的、方式及信息种类，并依法取得必要的单独同意。依法必须提供时，仅在合法要求的必要范围内提供。

如运营主体变更涉及个人信息转移，我们会告知接收方及联系方式，并要求其继续履行保护义务；改变原处理目的或方式时依法重新取得同意。除获得单独同意或法律另有规定外，我们不公开披露您的个人信息。

六、信息安全

游戏通过应用专用目录保存数据，使用临时写入、完整性核对和备份恢复等措施降低存档意外损坏风险。完整性核对不等于加密，无法代替设备锁屏和系统访问保护。请妥善保管设备，谨慎向他人提供存档或日志。

对主动反馈资料，我们将访问和使用范围限制为处理事项所必需的范围，保护联系邮箱及工作设备，并及时清理不再需要的资料。若发生个人信息安全事件，我们将及时采取补救措施，依法报告，并在需要时通过邮箱或政策页面公告告知受影响用户、可能影响及可采取的防护措施。

七、您的权利

1. 管理本机数据

您可通过“继续游戏”及大厅内的仓库、配装、干员和历史战绩等实际入口查看相应游戏记录，并通过设置调整声音与游戏选项。取消收藏仅改变相应战绩的收藏状态，不等于删除全部战绩或所有备份。

如需彻底清除独立安装版的本机数据，可在 Android 系统“设置 → 应用 → 搜打撤：我是摸红大王 → 存储”中选择“清除数据”或“清除存储空间”；不同设备名称可能不同。这会删除本机进度、物品、成长、战绩、收藏、设置和本应用目录内的备份，无法通过开发者云存档找回。仅清除缓存或开始新游戏不能代替清除应用数据。

如通过平台运行，请使用平台实际提供的本游戏数据管理方式，或联系平台客服，避免误清除整个 TapTap 的其他数据。平台副本和您自行保存的文件须另外删除；清除本机数据不等于删除已发送的邮件或服务商保存的信息。

2. 管理主动提供的信息

您可向 1900502733@qq.com 提出查阅、复制、更正、补充、删除个人信息、撤回同意、限制处理或解释本政策的请求；符合法定条件的信息转移请求，我们将依法协助。请说明相关邮件或事项，我们仅核对处理请求所必需的信息，不要求无关身份证明。

我们将在收到请求后十五个工作日内答复，合理请求不收费。撤回同意不影响此前依法进行的处理；撤回后将停止相应处理，并依法删除不再需要的信息。确因法律规定不能立即删除的，我们会说明原因，停止除必要存储和安全保护以外的处理；对无法满足的请求，会说明理由及可用的救济途径。

当前版本没有开发者注册或登录账号，因此不存在游戏账号注销流程；您可停止使用并清除本机数据。TapTap、邮箱等第三方账号及其信息管理，请使用对应服务的渠道。我们无法远程删除您设备中的存档。

八、未成年人信息保护

未满十八周岁的用户应与监护人共同阅读本政策，并在监护人指导下使用游戏。游戏没有自建实名账号或年龄验证功能，不向用户索取身份证件；使用平台服务时应遵守平台实际适用的规则。

不满十四周岁未成年人的个人信息属于敏感个人信息。当前游戏没有面向儿童的联网资料收集功能，也不主动索取儿童姓名、照片或证件。如需反馈，请由监护人代为联系，并避免提交儿童的无关个人信息。确需处理儿童个人信息时，我们将说明必要性和范围，依法取得监护人同意并采取专门保护措施。

监护人如发现未经授权的信息处理，可通过本政策邮箱联系我们。我们会核实并停止不应继续的处理，依法删除或协助相应服务商处理，并将结果反馈给监护人。

九、政策更新

我们会在本页面公布更新后的政策和更新日期。涉及信息处理目的、方式、种类或接收方的重要变化，将在发布页面作显著说明，并在新增处理开始前依法履行告知和取得同意等义务；仅继续离线游玩或看到网页更新不代表您同意新增处理。

本政策适用于目前已提供的功能，不授权尚未开展的广告或其他合作。后续功能变化时将同步更新实际告知。您可通过联系邮箱索取历史政策。
